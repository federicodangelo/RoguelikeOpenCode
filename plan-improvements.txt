ROGUELIKE GAME - IMPROVEMENT PLAN
=================================

This plan tracks architecture, performance, robustness, and maintainability
improvements found during code review. It is separate from plan.txt.

WORK RULES
----------
- [x] = done, [ ] = pending
- Keep behavior unchanged unless the step explicitly changes gameplay
- Run bun test, bun run typecheck, bun run lint, bun run build, and bun run verify after each phase
- Prefer small commits per step or milestone

HIGH-IMPACT FINDINGS
--------------------
- src/core/game.ts currently imports UI and platform code:
  - MessageLog from src/ui/menu.ts
  - Effect and spawnEffect from src/ui/effects.ts
  - CellView from src/platform/render.ts
- src/core/game.ts uses performance.now(), which couples core logic to the browser
- All runs currently use fixed BASE_SEED, so restarts repeat layouts and spawns
- Autosave runs after every keydown while in game
- Title drawing parses saved-run presence every frame
- buildScene uses linear find calls for items and monsters per rendered cell
- drawMinimap redraws every explored cell every dirty frame
- input.ts does not ignore e.repeat
- menu behavior depends on labels such as "Inventory"
- save version validation exists, but there is no migration path
- savedRunVersion and statusPower are currently unused
