ROGUELIKE GAME - IMPLEMENTATION PLAN
====================================

Stack: Bun + TypeScript (latest) + HTML Canvas 2D + 32x32 tileset

WORK RULES
----------
- [x] = done, [ ] = pending (update this file as work progresses)
- One commit per step/milestone
- Stop after each step for user review

STATUS: PHASE 0 in progress

PHASE 0 - Setup
---------------
1. Install Bun (winget install Oven-sh.Bun)
2. bun init -> package.json, tsconfig.json (strict mode)
3. Install dev deps: typescript, @types/bun
4. Project layout:
   src/
     main.ts          - entry point, game loop
     game.ts          - game state & turn manager
     map.ts           - dungeon generation
     entities.ts      - player, monsters, items
     combat.ts        - attack/defense calculations
     fov.ts           - field of view (shadowcasting)
     input.ts         - keyboard handling
     render.ts        - canvas rendering
     ui.ts            - HUD, messages, menus
     rng.ts           - seeded RNG
   public/
     index.html
     assets/tiles.png - 32x32 tileset
5. Scripts: dev (bun run), build (bun build --bundle), typecheck

PHASE 1 - Rendering core
------------------------
6. Canvas setup: fixed logical size (e.g. 30x20 tiles @ 32px = 960x640),
   scaled to fit window, crisp pixels (image-rendering: pixelated)
7. Tileset loader: load tiles.png, draw tiles by index
   (floor, wall, stairs, door, player, monster sprites, items)
8. Game loop: requestAnimationFrame, dirty-flag redraw

PHASE 2 - Dungeon generation
----------------------------
9. Room-and-corridor algorithm:
   - random non-overlapping rooms (minimap 40x30)
   - connect with L-shaped corridors
   - place stairs down, doors, items
10. Level progression: stairs descend to a new, harder level

PHASE 3 - Entities & FOV
------------------------
11. Entity system: player + monsters (HP, ATK, DEF, sprite, AI flag)
12. Turn-based loop: player acts -> monsters act
13. FOV: recursive shadowcasting; unexplored = black,
    explored-but-unseen = dimmed memory

PHASE 4 - Combat & AI
---------------------
14. Bump combat: move into enemy = attack; damage = ATK - DEF + variance
15. Monster AI: wander; if player visible, chase (simple pathing)
16. Death: player death screen + restart; monster drops corpse/loot

PHASE 5 - Items & progression
-----------------------------
17. Items: health potion, sword (+ATK), shield (+DEF), gold
18. Inventory: simple pick-up/use keys (i, g, u)
19. Simple XP/level-up for player (optional stretch)

PHASE 6 - UI & polish
---------------------
20. Message log panel (combat feedback)
21. HUD: HP bar, ATK/DEF, gold, depth level
22. Title screen, game-over screen, restart flow
23. Smooth-ish animations: damage flash, hit numbers (stretch)

PHASE 7 - Assets & build
------------------------
24. Tileset: generate or source a CC0 32x32 tileset
    (option: generate programmatically with canvas, or use a
    free pack like Kenney "Roguelike Sheet Redraw" - CC0)
25. bun build -> dist/ static bundle; verify playable in browser

PHASE 8 - Verification
----------------------
26. Typecheck clean (tsc --noEmit)
27. Manual playtest: movement, combat, FOV, descend 2+ levels
28. Final commit

MILESTONES (each = one commit)
------------------------------
M1: project scaffold + canvas shows a test tilemap
M2: dungeon generated and rendered
M3: player moves with FOV
M4: monsters + combat work
M5: items + UI + game over loop
M6: polished tileset + build script
