PHASE 1 - Rendering core [DONE]
------------------------------
[x] 1.1 Canvas setup: fixed logical size (30x20 tiles @ 32px = 960x640),
    scaled to fit window, crisp pixels (image-rendering: pixelated)
[x] 1.2 Tileset loader: load tiles.png, draw tiles by index
    (floor, wall, stairs, door, player, monster sprites, items)
    Note: tiles.png generated by tools/make-tiles.ts (14 tiles,
    16x16 pixel art scaled 2x; run `bun run tiles` to regenerate)
[x] 1.3 Game loop: requestAnimationFrame, dirty-flag redraw

PHASE 2 - Dungeon generation [DONE]
----------------------------------
[x] 2.1 Render layers: draw each cell in layer order
    (floor -> features(walls/doors/stairs/items) -> entities -> overlay/FOV)
    via a CellLayers structure in render.ts
[x] 2.2 Room-and-corridor algorithm:
    - random non-overlapping rooms (minimap 40x30)
    - connect with L-shaped corridors
    - place stairs down, doors, items
[x] 2.3 Level progression: stairs descend to a new, harder level
[x] 2.4 Multiple map generators, cycled per depth (src/mapgen/):
    - BSP: recursive space splitting, room per leaf, sibling corridors
    - Cellular automata: random fill + neighbor smoothing -> organic caves
    - Delaunay triangulation + Prim MST + 15% extra loop edges
    - Random walk (drunkard's walk) carving until open quota
[x] 2.5 Stairs up: new floors get an up-stair at the descent point;
    floors are cached per depth so going back returns the same map
